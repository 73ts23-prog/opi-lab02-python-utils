# Python Utilities

Навчальний набір Python-утиліт для лабораторної №2 з основ програмної інженерії.

Опис: калькулятор та конвертер довжини на Python.

## Автор і формат роботи

Цвіркунов Олексій Дмитрович, ІПЗ-21. Робота виконується індивідуально. Гілки демонструють різні завдання одного автора; внесок інших учасників і командне схвалення PR не заявляються.

## Можливості

- Арифметичні операції з перевіркою ділення на нуль.
- Перетворення довжини між метрами, кілометрами та сантиметрами.

## Запуск

Python 3.8 або новіший; сторонні бібліотеки не потрібні.

```console
python main.py
python -m unittest discover -s tests -v
```

## Workflow

Для кожного завдання створюється Issue, окрема feature-гілка та Pull Request. Після перевірки тестів зміни зливаються у main. Стабільна версія позначається тегом v1.0.0.

## Файли

- `python_utils/calculator.py` — калькулятор.
- `python_utils/converter.py` — конвертер довжини.
- `main.py` — демонстрація роботи.
- `tests/` — перевірки.
- `lab02-report.md` — звіт автора.
- `CHANGELOG.md` — історія змін.
